# NexLaunch Countdown

A futuristic, high-impact countdown timer designed for product launches and coming soon pages.

## 🚀 Features

- **Real-time Countdown**: Dynamic tracking of days, hours, minutes, and seconds.
- **Glassmorphic Blocks**: Modern visual design with transparency.
- **Notification Form**: Integrated email capture interface.
- **Fully Responsive**: Scalable design for mobile and desktop.

## 🛠️ Technologies Used

- **HTML5**, **CSS3**, **JavaScript**
